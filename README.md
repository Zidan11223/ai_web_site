# 🍽️ AI-Powered Restaurant Website

An intelligent and modern restaurant website built with responsive web technologies and integrated AI-based food recommendation features. This project provides users with an interactive dining experience by combining restaurant management features with personalized food suggestions.

---

## 🚀 Features

- 🏠 Modern Homepage Design
- 📋 Interactive Food Menu
- 🍔 Food Categories & Filtering
- 🤖 AI-Based Food Recommendation System
- 📍 Auto Location-Based Suggestions
- 🌦️ Weather & Time-Based Food Recommendations
- 🖼️ Dynamic Food Images
- 📱 Fully Responsive Design
- 📞 Contact & Reservation Section
- ⭐ Customer Reviews/Testimonial Section
- 🔍 Search Functionality
- ⚡ Fast & User-Friendly Interface

---

## 🧠 AI Recommendation System

The website includes an AI-powered recommendation engine that suggests food items based on:

- User Preferences
- Weather Conditions
- Time of Day
- Current Location
- Food Categories
- Mood-Based Suggestions

### Example Recommendations

| Condition | Suggested Food |
|-----------|----------------|
| 🌧️ Rainy Weather | Soup, Khichuri, Hot Coffee |
| ☀️ Hot Afternoon | Ice Cream, Cold Drinks |
| 🌙 Night Time | Pizza, Burger, BBQ |

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/restaurant-website.git
```

### 2️⃣ Go to Project Directory

```bash
cd restaurant-website
```

### 3️⃣ Open in VS Code

```bash
code .
```

### 4️⃣ Run the Project

You can run the website using:

- VS Code Live Server Extension
OR
- Open `index.html` directly in your browser

---

## 🔑 API Setup

Create a `.env` file in the root directory:

```env
OPENAI_API_KEY=your_openai_api_key
WEATHER_API_KEY=your_weather_api_key
```
